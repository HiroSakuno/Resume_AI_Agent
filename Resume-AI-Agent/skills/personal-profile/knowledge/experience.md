# Experience

Use this file as a reusable experience library. Each role is split into fixed subtopics so the LLM can quickly pick the most relevant bullets for a job description.

## How To Use

- When answering for a specific vacancy, choose the subtopics that match the role most closely.
- Prefer bullets that share the same language as the job posting.
- Keep the original facts, but re-order and combine them by relevance.
- Do not fabricate metrics. If a metric is unknown, leave it as an outcome without a number.
